# Summary

## What was changed and where
- **File**: `astropy/io/ascii/rst.py`
- **Method**: `RST.write()` and `RST.__init__()`
- **Changes**: 
  1. Modified `RST.write()` to use the separator line created by the parent `FixedWidth.write()` method instead of creating a new one
  2. Added `header_rows=None` parameter to `RST.__init__()` to properly pass it to the parent class

## Why
The original `RST.write()` method was creating its own separator line using `position_char * len(lines[0])`, which produced incorrect formatting. The parent `FixedWidth.write()` method already creates the correct separator line, so the fix was to use that existing separator line for the top and bottom borders instead of creating a new one.

## Anything not addressed
The fix handles the basic RST table format correctly. The change is minimal and focused on the specific issue of separator line creation. No edge cases or additional formatting requirements were identified that would need further modification.
