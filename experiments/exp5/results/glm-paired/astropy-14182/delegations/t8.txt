# RST Class Delimiter Fix

## What Changed and Where
- **File**: `astropy/io/ascii/rst.py`
- **Function**: `RST.__init__()` method
- **Change**: Modified delimiter settings from `delimiter = ""` to `delimiter = " "` for both `self.data.splitter.delimiter` and `self.header.splitter.delimiter`

## Why
This change ensures proper spacing between columns in RST output by using a single space delimiter instead of an empty string, preventing column concatenation and improving readability.
