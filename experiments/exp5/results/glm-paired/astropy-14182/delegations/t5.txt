# Summary

## Changes Made

Modified `/testbed/astropy/io/ascii/rst.py` to support the `header_rows` parameter with the following changes:

1. **RST.__init__()** - Updated to accept `header_rows` parameter and pass it to parent `FixedWidth` class
2. **SimpleRSTData** - Replaced static `start_line = 3` with dynamic calculation based on `header_rows` length (2 + len(header_rows))
3. **RST.write()** - Updated to dynamically find and use separator lines instead of hardcoded index

## Why

The changes enable the RST format to support multiple header rows (like name, unit, format) while maintaining the correct reStructuredText table format with proper separator lines.

## Notes

- The implementation maintains backward compatibility with the default `header_rows=['name']` behavior
- The separator line detection looks for lines containing '=' characters that don't start with '|'
- The `SimpleRSTData` class now calculates start_line dynamically based on the number of header rows
