# NDDataRef Class and Mask Handling Code in Astropy

## Summary

The NDDataRef class is found in `/testbed/astropy/nddata/nddata_withmixins.py` and combines NDData with three key mixins: NDArithmeticMixin, NDIOMixin, and NDSlicingMixin. Mask handling logic is primarily implemented in the NDArithmeticMixin (`/testbed/astropy/nddata/mixins/ndarithmetic.py`), which provides comprehensive mask propagation during arithmetic operations through the `_arithmetic_mask` method and related functionality.

## Key Mask Propagation Logic

The primary mask handling logic is in `NDArithmeticMixin._arithmetic_mask` method:

1. **Handle None masks**: If either operand has no mask or handle_mask is None, return appropriate None mask
2. **Single mask cases**: Return deepcopy of the existing mask if only one operand has a mask
3. **Dual mask cases**: Apply the handle_mask function (default is bitwise OR) to combine masks
4. **Broadcasting support**: Handles cases where masks have different shapes through numpy broadcasting rules

The arithmetic operations support different mask handling modes:
- `None`: Result has no mask
- `'first_found'` or `'ff'`: Use mask from first operand that has one
- Custom callable: User-provided function to combine masks
