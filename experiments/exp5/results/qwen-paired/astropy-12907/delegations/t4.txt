```python
def _cstack(left, right):
    """
    Function corresponding to '&' operation.

    Parameters
    ----------
    left, right : `astropy.modeling.Model` or ndarray
        If input is of an array, it is the output of `coord_matrix`.

    Returns
    -------
    result : ndarray
        Result from this operation.

    """
    noutp = _compute_n_outputs(left, right)

    if isinstance(left, Model):
        cleft = _coord_matrix(left, 'left', noutp)
    else:
        cleft = np.zeros((noutp, left.shape[1]))
        cleft[: left.shape[0], : left.shape[1]] = left
    if isinstance(right, Model):
        cright = _coord_matrix(right, 'right', noutp)
    else:
        cright = np.zeros((noutp, right.shape[1]))
        cright[-right.shape[0]:, -right.shape[1]:] = 1

    return np.hstack([cleft, cright])
```

### Explanation of Processing:

1. **Input Handling**:
   - The function `_cstack` takes two arguments: `left` and `right`, which can either be `Model` instances or coordinate matrices (ndarrays).
   - It first calculates the total number of outputs (`noutp`) for the compound model using `_compute_n_outputs`.

2. **Coordinate Matrix Generation**:
   - If `left` is a `Model`, it generates its coordinate matrix using `_coord_matrix` with position `'left'`.
   - If `left` is already a coordinate matrix (ndarray), it creates a zero matrix of appropriate size and fills the top-left portion with the data from `left`.

   - Similarly, if `right` is a `Model`, it generates its coordinate matrix using `_coord_matrix` with position `'right'`.
   - If `right` is already a coordinate matrix (ndarray), it creates a zero matrix of appropriate size and fills the bottom-right portion with ones (indicating full connectivity).

3. **Combining Matrices**:
   - The function horizontally stacks (`np.hstack`) the two generated coordinate matrices (`cleft` and `cright`) to form the final result.
   - This stacking effectively combines the coordinate dependencies of both operands side-by-side, preserving their individual contributions to the overall transformation's separability structure.

This approach allows the function to correctly handle both simple models and precomputed coordinate matrices, ensuring that the resulting matrix accurately reflects the combined behavior of the two operands under an '&' operation.
