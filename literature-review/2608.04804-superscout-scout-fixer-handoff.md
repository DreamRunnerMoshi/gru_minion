# SuperScout

- **Citation**: [arXiv:2608.04804](https://arxiv.org/abs/2608.04804)
- **Cited in**: [DESIGN.md](../DESIGN.md) §Investigation: SWE-bench family / prior art

## Thesis

A small "scout" model explores a repository and produces a sandbox-verified handoff to a frontier "fixer" model, which then writes the actual patch.

## Key findings

- Matched Opus's solve rate on SWE-bench Pro at **~1/5 the cost**.
- **Key finding: the verified handoff itself drove the gain, not the model-routing choice** — i.e. the improvement wasn't just "cheap model explores, expensive model fixes," it specifically depended on the handoff being sandbox-*verified* before the frontier model acted on it.

## What we took from it

**Directly supports this project's core hypothesis** — a cheap model can do the exploration/context-gathering tier at a fraction of the cost, as long as the handoff to the expensive tier is verified rather than trusted blindly. This is the closest existing result to what this project is trying to build and measure (Phase 2's B condition: frontier Gru + self-hosted minion), and specifically flags that *verification of the handoff* is the load-bearing mechanism, not just cost-tiered model routing on its own.

## Caveats

None flagged in the source doc — treated as a strong, directly-relevant positive result.
