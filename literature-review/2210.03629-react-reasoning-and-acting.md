# ReAct: Synergizing Reasoning and Acting in Language Models

- **Citation**: Yao et al., ICLR 2023 — [arXiv:2210.03629](https://arxiv.org/pdf/2210.03629)
- **Cited in**: [design/architecture/02-gru-minion-protocol.md](../design/architecture/02-gru-minion-protocol.md) §1

## Thesis

Interleaving reasoning traces with action/tool calls — think, act, observe, think again — outperforms both pure chain-of-thought (reason only, never touch the environment) and pure acting (act without explicit intermediate reasoning).

## Key findings

- On HotpotQA/Fever, interleaving reasoning with a Wikipedia API call reduced hallucination and error-propagation vs. CoT alone.
- On ALFWorld and WebShop, ReAct beat imitation/RL baselines by **34 and 10 absolute points** respectively, using only 1-2 in-context examples.

## What we took from it

The closest general foundation for Gru's core mechanism: Gru's planning is not one-shot generation — it can pause mid-reasoning, delegate a bounded information-gathering sub-call to a minion, get findings back, and continue reasoning with that grounded context. This is directly analogous to ReAct's think→act→observe→think loop, just with "act" being "delegate to a minion" instead of "call a tool" directly.

## Caveats

None flagged in the source design doc — treated as solid, general-purpose foundational evidence, not project-specific or unverified.
