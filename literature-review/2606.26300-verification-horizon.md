# The Verification Horizon

- **Citation**: [arXiv:2606.26300](https://arxiv.org/abs/2606.26300)
- **Cited in**: [DESIGN.md](../DESIGN.md) §Reward hacking / verification gaming

## Thesis

Examines whether any single verification scheme generalizes robustly across different task types.

## Key findings

- No single verification scheme is robust across all task types — robustness is task-shape-dependent.

## What we took from it

Verification design in this project likely needs to vary by subtask shape (e.g. a `synthesize` subtask's FAIL_TO_PASS check vs. a research/context-gathering subtask's lighter checkability requirement per [MAMM-Refine](./2503.15272-mamm-refine-multiagent-faithfulness.md)'s implications), rather than using one fixed verification template for every subtask type in `PLAN_FORMAT.md`.

## Caveats

None flagged — a general finding used to justify per-task-type verification design, not a specific number this project has adopted.
