## Your actions

- **`think`** — spend a turn on a decision instead of on work.

- **`run_check`** — run a shell command against the repository and see the result.

- **`finish`** — declare the task complete, with a verification that should confirm it.

Exactly one action per turn.

Ground factual claims in something you actually ran and saw — a check's output, a file you read — not in what seems likely to be true. If you haven't run the command that would confirm it, treat it as unconfirmed.
